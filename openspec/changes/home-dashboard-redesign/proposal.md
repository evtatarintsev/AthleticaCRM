## Why

Главная показывает четыре виджета одинаковыми серыми списками в один ряд: при трёх-четырёх
включённых карточки сжимаются, взгляду не за что зацепиться, а «что сейчас» не отличается от
«что было утром». Карточка группы и карточка клиента уже получили новое оформление — плитки,
карточки с заголовком, цветные метки состояния; главная выбивается из этого стиля.

Данных для живой главной уже достаточно: время занятий, дата рождения, дата незакрытого
занятия приходят в существующих ответах. Не хватает оформления, которое
покажет их с первого взгляда.

Макет, согласованный с заказчиком: `mockups/home-dashboard.html` (компьютер, телефон,
спокойный день). Варианты с плитками сводки, доской из колонок и шкалой залов рассмотрены и
отклонены — см. `design.md`.

## What Changes

- Главная сохраняет обычный заголовок «Главная» и шестерёнку общих настроек.
  Блок с датой и приветствием исключён из макета и плана.
- Виджеты стоят сеткой в две колонки (на телефоне — в одну) вместо одного ряда; порядок
  и видимость по-прежнему задаются общими настройками.
- Заголовок карточки: цветная иконка вида виджета, название, счётчик, шестерёнка карточки.
  Цвета закреплены за видом: «Занятия сегодня» — синий, «Должники» — красный,
  «Дни рождения» — розовый, «Незакрытые журналы» — жёлтый.
- «Занятия сегодня» — лента дня: прошедшие по времени занятия приглушены, идущее подсвечено
  с меткой «идёт», следующее выделено цветом без текстовой метки. Состояние считается по часам
  браузера.
- «Должники» — аватар клиента в строке, сумма долга справа.
- «Дни рождения» — у именинника сегодня метка «сегодня» с иконкой торта, у остальных — дата;
  возраст под именем. Иконки карточек и меток декоративные, кнопки настроек имеют доступные названия.
- «Незакрытые журналы» — возраст журнала меткой («вчера», «N дней назад»); у сегодняшнего
  метки нет.
- Пустой список — зелёная галочка и сообщение, а не просто серый текст.
- Метки дней рождения и возраста журналов пересчитываются при смене дня без перезагрузки;
  метка «идёт» не обрезается на телефоне. Порог одной/двух колонок — 768 CSS-пикселей.
- Набор виджетов, их индивидуальные и общие настройки, запросы к API не меняются.
- **BREAKING**: нет.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `web-client/home-dashboard`: появляются требования к шапке главной, раскладке виджетов сеткой,
  оформлению заголовка карточки, состояниям ленты «Занятия сегодня», меткам дней рождения и
  незакрытых журналов, пустым состояниям. Требование про аватары дней рождения дополняется
  меткой «сегодня» и датой.

## Impact

- `web/src/home/`: `HomePage.tsx` (шапка, сетка), `ListWidgetCard.tsx`, `SessionsWidgetCard.tsx`,
  `DebtorsWidgetCard.tsx`, `BirthdaysWidgetCard.tsx`, `UnclosedSessionsWidgetCard.tsx`,
  `WidgetSettingsButton.tsx`; новый общий каркас карточки виджета и чистые функции состояния
  ленты и возраста журнала с тестами, общие часы для временных состояний виджетов.
- `web/src/i18n/ru.ts`, `en.ts` — «идёт», «сегодня», «вчера», «N дней назад»;
  `web/src/i18n/format.ts` — дата дня рождения без года.
- Сервер, `shared`, сгенерированные контракты — без изменений.
