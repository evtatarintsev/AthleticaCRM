# AI-помощник

Помощник умеет добавлять нового клиента из свободной фразы. Он показывает карточку
со всеми данными и сохраняет клиента только после подтверждения кнопкой «ОК» или
следующим сообщением («да»). Исправления отправляются новым сообщением: прежняя
карточка заменяется. Повторное подтверждение возвращает того же клиента.

## Подключение сервера

Все параметры необязательны. Без них CRM работает, помощник недоступен, кнопка
чата скрыта. Тесты используют fake-модель и не требуют AI-ключа.

| Переменная | Значение |
| --- | --- |
| `AI_PROVIDER` | `openai`, `anthropic`, `openrouter` или `deepseek` |
| `AI_MODEL` | Идентификатор модели с поддержкой tool calling у выбранного провайдера |
| `AI_API_KEY` | Серверный ключ общего аккаунта провайдера |

Заполните все три параметра в окружении сервера (для production — `.env` рядом с Compose).
Compose передаёт их в `application.conf`. Ключ и модель не возвращаются через API
и не вводятся в интерфейсе организации. При изменении подключения перезапустите
сервер. Оператор оплачивает общее подключение; квота сообщений ограничивает
использование, но не является финансовым лимитом провайдера.

Для прямого подключения DeepSeek с ключом из https://platform.deepseek.com/api_keys:

```dotenv
AI_PROVIDER=deepseek
AI_MODEL=deepseek-flash
AI_API_KEY=<ваш ключ DeepSeek>
```

Запросы идут в `https://api.deepseek.com/chat/completions` через штатный клиент
DeepSeek в Koog. Режим рассуждений отключён, чтобы сохранить бюджет короткого хода
и ответов с вызовами инструментов. Модель можно заменить на `deepseek-v4-pro`.
Актуальные модели и параметры: https://api-docs.deepseek.com/.

Для локального запуска добавьте эти переменные с `export` в игнорируемый `.envrc`,
загрузите его (`source .envrc`) и запустите `./gradlew server:run --args=serve`.
В production внесите их в `.env` на сервере и пересоздайте контейнер:
`docker compose -f docker-compose.prod.yaml up -d server`.
Если используете `.env.prod`, передайте `--env-file .env.prod` явно.
Файлы с настоящим ключом не добавляйте в Git.

## Включение организации

Владелец открывает «Настройки → AI-помощник», включает его и задаёт положительный
суточный лимит (начальное значение — 100). До явного включения помощник выключен.
Владелец имеет доступ по общему правилу всех прав. Сотрудникам нужно выдать
`CAN_USE_ASSISTANT` через роль или персонально; персональный отзыв имеет приоритет.

Счётчик общий для всех сотрудников организации, день определяется её часовым
поясом. Принятое сообщение расходует одну единицу, включая ошибку провайдера.
Подтверждение кнопкой, чтение и отклонённые сообщения (нет доступа, занят диалог,
помощник выключен, лимит исчерпан) единицы не расходуют.

## Данные и ограничения

Имена и контакты создаваемых клиентов, определения дополнительных полей и короткая
история личного диалога передаются внешнему провайдеру. Владелец включает передачу
явно. Условия обработки данных и доступ к серверному ключу обеспечивает оператор.
История хранится в PostgreSQL и доступна только соответствующему сотруднику своей
организации. Срок хранения и удаление истории пока не реализованы.

Вход — до 4000 символов. Ход ограничен 45 секундами, шестью обращениями к модели,
шестью вызовами tools и размером ответа. В контекст входят до восьми последних целых
успешных обменов. Сеть не удерживает транзакцию БД. nginx ждёт `/api/assistant/` до
90 секунд. При потере ответа UI перечитывает диалог, автоматически модель не вызывает.

Первая версия не ищет клиентов, не читает расписание и аналитику, не рассчитывает
зарплаты, не меняет существующих клиентов и не отправляет сообщения. Пол может быть
предположен по имени: проверьте его вместе с остальными полями до подтверждения.
Текстовое подтверждение распознаёт модель; для однозначного сохранения используйте
«ОК». Успешное создание показывает только серверная квитанция со ссылкой на клиента.

Аргументы tools и ошибки провайдера могут содержать персональные данные, поэтому
логирование `ai.koog` отключено. Прикладная диагностика содержит только ID хода,
статус и длительность; не включайте трассировку запросов к AI в production.

## Откат

Выключите помощника в настройках организации либо удалите AI-параметры и
перезапустите сервер. История остаётся в БД и снова доступна после включения.
Созданные клиенты остаются обычными клиентами CRM. Добавочные таблицы можно оставить
при развёртывании прежнего кода; откат не должен удалять клиентов.
