# Замер сборки контекста запроса

## Сценарий

`server/src/test/kotlin/org/athletica/crm/routes/ContextFromRequestBenchmark.kt`:
Ktor `testApplication` с полной конфигурацией сервера и PostgreSQL 18 в TestContainers.
Сотрудник (не владелец) с тремя ролями (по 1–2 права), персональной выдачей и отзывом,
доступом к двум выбранным филиалам. Защищённый маршрут `/bench/context` измеряет только
вызов `contextFromRequest`. 200 запросов прогрева вне выборки, затем 1000 последовательных.

Запуск одной командой (тест пропускается без переменной окружения):

```bash
CONTEXT_BENCH=1 ./gradlew :server:test --tests "*ContextFromRequestBenchmark*" --rerun && grep -o "BENCH[^<]*" server/build/test-results/test/TEST-org.athletica.crm.routes.ContextFromRequestBenchmark.xml
```

## Среда

- Apple M4, macOS 26.7.1, Docker 29.9.3 (PostgreSQL 18 в TestContainers, локально)
- JVM тестов — Gradle-тулчейн проекта, Gradle 9.7.1
- Данные и параметры одинаковы до и после

## До изменения

Ревизия `1ac4d87f` (5 SQL на загрузку сотрудника). Три прогона:

| Прогон | Медиана | p90 |
| --- | ---: | ---: |
| 1 | 1.673 ms | 2.729 ms |
| 2 | 1.706 ms | 2.567 ms |
| 3 | 1.673 ms | 2.527 ms |

Медиана: **1.67 ms**.

## После изменения

Ревизия `1ac4d87f` + незакоммиченные изменения этого change (1 SQL на загрузку сотрудника).
Та же машина, та же команда и данные. Три прогона:

| Прогон | Медиана | p90 |
| --- | ---: | ---: |
| 1 | 1.246 ms | 1.735 ms |
| 2 | 1.248 ms | 1.804 ms |
| 3 | 1.181 ms | 1.862 ms |

Медиана: **1.25 ms** (до — 1.67 ms, примерно −25 %).

PostgreSQL здесь локальный, задержка round-trip минимальна; при сетевой БД разница
на каждый сэкономленный запрос больше. Порог задержки тестом не фиксируется.

## Критерии issue #229

| Критерий | Статус | Где |
| --- | --- | --- |
| Нет пяти последовательных SELECT, число зафиксировано | готово: 5 → 1 | `DbEmployeesTest` (счётчик `sql()`) |
| Повторное чтение в `assistant/status` устранено без ослабления актуальности | готово: 2 → 1 загрузка на запрос | `AssistantRoutesTest`, `AssistantGuardTest` |
| Изоляция организаций, владелец, роли, выдачи/отзывы, филиалы, `EMPLOYEE_NOT_FOUND` | готово | `DbEmployeesTest` |
| Изменения доступа видны в следующем запросе, кэша нет | готово | `AssistantRoutesTest`, тесты `save` в `DbEmployeesTest` |
| Регрессионные проверки и остальные вызывающие `byId/byIds` | готово | `./gradlew build`: 842 теста |
| Сравнение до/после на прогретом сценарии | готово локально | этот файл |

сравнение сделано только на машине разработчика.
