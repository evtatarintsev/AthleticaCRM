## ADDED Requirements

### Requirement: Панели задач в карточке клиента

Блок «Задачи» в карточке клиента SHALL открывать панели задач справа поверх карточки клиента, не
уводя со страницы клиента. Действие «Создать задачу» в блоке SHALL открывать панель создания задачи,
а нажатие на задачу в блоке SHALL открывать карточку этой задачи. Поведение панелей (поля, проверки,
смена статуса, исполнителя и вложений, редактирование, подтверждение при закрытии с несохранёнными
данными) SHALL совпадать с панелями раздела задач. Открытые из карточки клиента панели SHALL NOT
записываться в адрес страницы. После создания или изменения задачи блок «Задачи» и предупреждение о
просроченных задачах в карточке клиента SHALL обновляться.

#### Scenario: Создание задачи из карточки клиента

- **WHEN** в карточке клиента «Петров» пользователь нажимает «Создать задачу» в блоке «Задачи»
- **THEN** справа открывается панель создания задачи, под ней остаётся карточка клиента «Петров»,
  адрес страницы не меняется

#### Scenario: Новая задача появляется в блоке

- **WHEN** в панели, открытой из карточки клиента «Петров», пользователь вводит заголовок и нажимает
  «Создать»
- **THEN** задача создаётся привязанной к клиенту «Петров», панель закрывается, задача появляется в
  блоке «Задачи» карточки

#### Scenario: Открытие задачи из карточки клиента

- **WHEN** в карточке клиента пользователь нажимает на задачу в блоке «Задачи»
- **THEN** справа открывается карточка задачи, под ней остаётся карточка клиента, адрес страницы не
  меняется

#### Scenario: Изменение задачи отражается в блоке

- **WHEN** в карточке задачи, открытой из карточки клиента, пользователь меняет статус на «Выполнена»
- **THEN** статус сохраняется, и строка задачи в блоке «Задачи» показывает новый статус

#### Scenario: Отвязка задачи от клиента

- **WHEN** в карточке задачи, открытой из карточки клиента, пользователь редактирует задачу, убирает
  клиента и сохраняет
- **THEN** карточка задачи остаётся открытой, а задача пропадает из блока «Задачи» карточки клиента

## MODIFIED Requirements

### Requirement: Привязка задачи к клиенту

В формах создания и редактирования задачи клиент SHALL выбираться через панель выбора клиента в
одиночном режиме. Выбранный клиент SHALL отображаться в форме по имени, и привязку SHALL можно
убрать. Выбор клиента SHALL попадать в форму и сохраняться вместе с ней, а не сразу. Задача без
клиента SHALL оставаться допустимой.

Исключение — форма создания, открытая из карточки клиента: клиент этой карточки SHALL быть выбран
заранее и показываться по имени как неизменяемое поле. Выбрать другого клиента или убрать привязку в
такой форме SHALL NOT быть возможно, и задача SHALL создаваться привязанной к этому клиенту. Заранее
выбранный клиент сам по себе SHALL NOT считаться несохранёнными данными при закрытии формы.

#### Scenario: Привязка при создании

- **WHEN** в форме создания пользователь выбирает клиента «Петров» и создаёт задачу
- **THEN** задача создаётся привязанной к клиенту «Петров», карточка показывает его имя

#### Scenario: Отвязка при редактировании

- **WHEN** в форме редактирования задачи с клиентом пользователь убирает клиента и сохраняет
- **THEN** задача больше не привязана к клиенту

#### Scenario: Клиент заранее выбран в карточке клиента

- **WHEN** пользователь открывает создание задачи из карточки клиента «Петров»
- **THEN** в форме показан клиент «Петров», а действий выбора другого клиента и отвязки нет

#### Scenario: Закрытие формы без ввода

- **WHEN** пользователь открывает создание задачи из карточки клиента и сразу закрывает панель
- **THEN** панель закрывается без запроса подтверждения
