## ADDED Requirements

### Requirement: Переход из участника занятия в его историю посещений

Имя участника в блоке посещаемости карточки занятия SHALL быть интерактивным элементом, открывающим
боковую панель ученика поверх карточки занятия без ухода со страницы. Панель SHALL показывать ФИО
ученика, ссылку на карточку клиента, сводку и историю посещений (см. `web-client/client-attendance-history`).
Открытый ученик SHALL отражаться в URL search-параметром `client`.

#### Scenario: Открытие панели ученика

- **WHEN** пользователь кликает по имени участника в списке посещаемости
- **THEN** справа открывается панель с историей посещений этого ученика
- **AND** URL карточки занятия содержит `?client=<clientId>`
- **AND** отметки посещаемости остальных участников на странице не меняются

#### Scenario: Текущее занятие в истории ученика

- **WHEN** панель ученика открыта
- **THEN** в истории есть строка текущего занятия, она визуально выделена и показывает тот же статус,
  что и переключатель посещаемости ученика на странице

#### Scenario: Отметка отражается в открытой панели

- **WHEN** панель ученика открыта, и пользователь меняет его статус посещения на странице занятия
- **THEN** строка текущего занятия в панели показывает новый статус, а сводка пересчитывается

#### Scenario: Закрытие панели

- **WHEN** панель ученика открыта, и пользователь закрывает её крестиком, клавишей Esc или кнопкой
  «Назад» браузера
- **THEN** панель закрывается, параметр `client` исчезает из URL, пользователь остаётся на карточке
  занятия

#### Scenario: Переход в карточку клиента

- **WHEN** пользователь нажимает «Открыть карточку» в панели ученика
- **THEN** открывается страница `/clients/$clientId` этого ученика

#### Scenario: Некорректный параметр client

- **WHEN** пользователь открывает карточку занятия с невалидным значением `?client=`
- **THEN** карточка занятия открывается без панели и без ошибки
