# Spec Delta

## ADDED Requirements

### Requirement: CRM не встраивается в чужие страницы

Страницы хоста `app.<домен>` SHALL запрещать браузеру показывать их внутри iframe на
страницах любого сайта. Исключение SHALL действовать только для страниц виджетов
расписания `/widget/...`.

#### Scenario: Попытка встроить CRM

- **WHEN** сторонняя страница вставляет iframe с `https://app.<домен>/clients`
- **THEN** браузер отказывается показывать страницу CRM внутри iframe

#### Scenario: Встраивание виджета

- **WHEN** сторонняя страница вставляет iframe с `https://app.<домен>/widget/<ключ>`
- **THEN** браузер показывает страницу виджета внутри iframe
