# Spec Delta

## ADDED Requirements

### Requirement: Наполнение организации данными

Команда `admin org seed` SHALL наполнять указанную организацию данными по правилам наполнения организации. Организация SHALL указываться так же, как в других командах над конкретной организацией. Профиль объёма SHALL задаваться опцией `--size` со значениями `small`, `medium`, `large`, по умолчанию `small`; зерно генератора — опцией `--seed`, по умолчанию фиксированное. После наполнения SHALL выводиться название организации и число созданных клиентов, групп и занятий.

#### Scenario: Наполнение пустой организации

- **WHEN** выполняется `admin org seed` с организацией, созданной регистрацией и ещё не заполненной
- **THEN** организация наполняется данными профиля `small`, выводятся её название и число созданных клиентов, групп и занятий, код возврата нулевой

#### Scenario: Выбор профиля и зерна

- **WHEN** выполняется `admin org seed` с `--size=large --seed=42`
- **THEN** организация наполняется профилем `large` с зерном 42

#### Scenario: Непустая организация

- **WHEN** выполняется `admin org seed` с организацией, в которой уже есть клиенты или группы
- **THEN** выводится сообщение об ошибке в поток ошибок, приложение завершается с ненулевым кодом возврата, данные организации не изменяются

#### Scenario: Недопустимый профиль

- **WHEN** `admin org seed` вызвана с `--size`, не входящим в `small`, `medium`, `large`
- **THEN** выводится ошибка разбора аргументов, приложение завершается с ненулевым кодом возврата, подключение к базе данных не открывается

### Requirement: Наполнение не создаёт учётных записей

Команда `admin org seed` SHALL NOT создавать пользователей, принимать или выводить пароли. Вход в наполненную организацию SHALL выполняться учётной записью её владельца, существовавшей до наполнения.

#### Scenario: Вывод без учётных данных

- **WHEN** `admin org seed` успешно завершилась
- **THEN** вывод не содержит логинов и паролей, а число учётных записей для входа в организацию не изменилось
