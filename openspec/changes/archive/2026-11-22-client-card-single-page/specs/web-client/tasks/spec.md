## MODIFIED Requirements

### Requirement: Панели задач в карточке клиента

Если в организации включён раздел «Задачи» карточки клиента (`client-card-sections`), карточка
клиента SHALL показывать карточку «Задачи» с незавершёнными задачами клиента, действием «Создать»
и действием «Все задачи», открывающим панель «Задачи» со всеми доступными задачами клиента.
Действие «Создать» в карточке, «Создать задачу» в панели и в меню «⋯» шапки SHALL открывать
панель создания задачи, а нажатие на задачу в карточке, в панели или в строке просроченных задач
«Требует внимания» SHALL открывать карточку этой задачи справа поверх карточки клиента. Поведение
панелей (поля, проверки, смена статуса, исполнителя и вложений, редактирование, подтверждение при
закрытии с несохранёнными данными) SHALL совпадать с панелями раздела задач. Открытые из карточки
клиента панели SHALL NOT записываться в адрес страницы. После создания или изменения задачи
карточка и панель «Задачи», счётчики и строка просроченных задач SHALL обновляться. Если раздел
выключен, карточка клиента SHALL NOT показывать задачи, а раздел «Задачи» приложения SHALL работать
как прежде.

#### Scenario: Создание задачи из карточки клиента

- **WHEN** в карточке клиента «Петров» пользователь нажимает «Создать» в карточке «Задачи»
- **THEN** справа открывается панель создания задачи, под ней остаётся карточка клиента «Петров»,
  адрес страницы не меняется

#### Scenario: Новая задача появляется в блоке

- **WHEN** в панели, открытой из карточки клиента «Петров», пользователь вводит заголовок и нажимает
  «Создать»
- **THEN** задача создаётся привязанной к клиенту «Петров», панель закрывается, задача появляется в
  карточке «Задачи», её счётчик увеличивается

#### Scenario: Открытие задачи из карточки клиента

- **WHEN** в карточке клиента пользователь нажимает на задачу в карточке «Задачи»
- **THEN** справа открывается карточка задачи, под ней остаётся карточка клиента, адрес страницы не
  меняется

#### Scenario: Все задачи

- **WHEN** пользователь нажимает «Все задачи», а в панели — на выполненную задачу
- **THEN** открывается панель «Задачи» со всеми задачами клиента, поверх неё — карточка задачи;
  после её закрытия снова виден список

#### Scenario: Изменение задачи отражается в блоке

- **WHEN** в карточке задачи, открытой из карточки клиента, пользователь меняет статус просроченной
  задачи на «Выполнена»
- **THEN** статус сохраняется, задача пропадает из карточки «Задачи», а строка о просроченной
  задаче в «Требует внимания» пропадает

#### Scenario: Отвязка задачи от клиента

- **WHEN** в карточке задачи, открытой из карточки клиента, пользователь редактирует задачу, убирает
  клиента и сохраняет
- **THEN** карточка задачи остаётся открытой, а задача пропадает из карточки и панели «Задачи»

#### Scenario: Раздел выключен

- **WHEN** раздел «Задачи» карточки клиента выключен, у клиента есть задачи
- **THEN** в карточке клиента нет карточки «Задачи» и действия «Создать задачу», а в разделе
  «Задачи» приложения задачи клиента видны
