## ADDED Requirements

### Requirement: Оплата клиента из приложения

Оплата, которую клиент провёл в мобильном приложении (`client-app-payments`), SHALL записываться по тем же правилам, что и оплата, принятая сотрудником: пополнение аванса без продажи или оплата продажи с аванса при её оформлении, по статье «Поступления от клиентов». У такой оплаты SHALL NOT быть автора-сотрудника; история баланса клиента и кассовый журнал SHALL показывать вместо автора отметку «из приложения».

#### Scenario: Пополнение из приложения в истории

- **WHEN** мама пополнила баланс Ивана на 1 200 ₽ из приложения
- **THEN** история баланса Ивана показывает оплату +1 200 ₽ с отметкой «из приложения» вместо автора

### Requirement: Отмена оплаты из приложения

Оплату из приложения SHALL отменять только сотрудник с правом управления финансами, по общим правилам отмены оплаты: у неё нет автора, поэтому правило «свою сегодняшнюю оплату» к ней не применяется.

#### Scenario: Отмена оплаты из приложения

- **WHEN** сотрудник с правом управления финансами отменяет ошибочную оплату из приложения
- **THEN** оплата сторнируется по общим правилам отмены оплаты

#### Scenario: Без права управления финансами

- **WHEN** администратор с правом только приёма оплат отменяет сегодняшнюю оплату из приложения
- **THEN** отмена отклоняется с ошибкой доступа
