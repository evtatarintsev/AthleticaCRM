## Why

Занятие (сессия группы) сейчас нельзя открыть отдельно: расписание и главная показывают только
плитки/строки без перехода к деталям. Нужна карточка занятия — единая точка, где видно состав
группы, тренеров, зал, время и статус, и откуда доступны действия над занятием. Реальный набор
действий и посещаемость ещё не спроектированы на бэкенде, поэтому сначала фиксируем дизайн UI на
моках, без завязки на API — это быстрее и дешевле для итераций, чем сразу проектировать контракты.

## What Changes

- Новая страница `SessionDetailPage` (`web/src/schedule` или отдельный модуль `session`) с маршрутом
  `/sessions/$sessionId`, отображающая: группу, дату/время, зал, статус (запланировано / завершено /
  отменено), список тренеров, список участников группы.
- Блок действий над занятием: отменить, перенести, сменить зал, сменить тренеров, оставить заметку —
  все действия в этой итерации **мокнуты** (показывают локальный отклик UI, ничего не отправляют
  на сервер).
- Блок посещаемости: для каждого участника — переключатель статуса (был / не был / болел / опоздал),
  состояние хранится только в локальном state страницы, не персистентно.
- Все данные страницы (занятие, участники, тренеры, зал) — мок-данные внутри фронтенда, без реальных
  API-вызовов и без изменений `shared`/`server`.
- Ссылки на карточку занятия из `ScheduleWeekGrid` (клик по занятию в расписании) и с главной страницы
  (сегодняшнее расписание, `HomePage`).
- **BREAKING**: нет — новая страница и новые ссылки, существующее поведение не меняется.

## Capabilities

### New Capabilities
- `web-client/session-detail`: страница детальной карточки занятия — состав данных, действия
  (мокнутые), отметки посещаемости (мокнутые), переходы на страницу из расписания и с главной.

### Modified Capabilities
(нет — переходы из расписания/главной являются частью новой capability, а не изменением
существующих требований к `schedule`/`web-client/app-shell`)

## Impact

- Затронутый код: `web/src/schedule/ScheduleWeekGrid.tsx` (клик по занятию → ссылка), `web/src/home/*`
  (ссылка из сегодняшнего расписания), `web/src/app/router.tsx` (новый маршрут), новый модуль страницы
  и мок-данных (`web/src/sessions/` или аналогично).
- Не затронуто: `server/`, `shared/`, `openspec/specs/schedule`, `openspec/specs/web-client/app-shell`
  — реального API ещё нет, эта карточка полностью на моках.
- Зависимости: не добавляются.
