## MODIFIED Requirements

### Requirement: Панели задач в карточке клиента

Если в организации включён раздел «Задачи» карточки клиента (`client-card-sections`), вкладка
«Задачи» карточки клиента SHALL открывать панели задач справа поверх карточки клиента, не уводя со
страницы клиента. Действие «Создать задачу» на вкладке и в меню «⋯» шапки SHALL открывать панель
создания задачи, а нажатие на задачу на вкладке или в строке просроченных задач «Требует внимания»
SHALL открывать карточку этой задачи. Поведение панелей (поля, проверки, смена статуса, исполнителя
и вложений, редактирование, подтверждение при закрытии с несохранёнными данными) SHALL совпадать с
панелями раздела задач. Открытые из карточки клиента панели SHALL NOT записываться в адрес
страницы. После создания или изменения задачи вкладка «Задачи», её счётчик и строка просроченных
задач SHALL обновляться. Если раздел выключен, карточка клиента SHALL NOT показывать задачи, а
раздел «Задачи» приложения SHALL работать как прежде.

#### Scenario: Создание задачи из карточки клиента

- **WHEN** в карточке клиента «Петров» пользователь нажимает «Создать задачу» на вкладке «Задачи»
- **THEN** справа открывается панель создания задачи, под ней остаётся карточка клиента «Петров»,
  адрес страницы не меняется

#### Scenario: Новая задача появляется на вкладке

- **WHEN** в панели, открытой из карточки клиента «Петров», пользователь вводит заголовок и нажимает
  «Создать»
- **THEN** задача создаётся привязанной к клиенту «Петров», панель закрывается, задача появляется на
  вкладке «Задачи», её счётчик увеличивается

#### Scenario: Открытие задачи из карточки клиента

- **WHEN** в карточке клиента пользователь нажимает на задачу на вкладке «Задачи»
- **THEN** справа открывается карточка задачи, под ней остаётся карточка клиента, адрес страницы не
  меняется

#### Scenario: Изменение задачи отражается на вкладке

- **WHEN** в карточке задачи, открытой из карточки клиента, пользователь меняет статус просроченной
  задачи на «Выполнена»
- **THEN** статус сохраняется, строка задачи на вкладке показывает новый статус, а строка о
  просроченной задаче в «Требует внимания» пропадает

#### Scenario: Отвязка задачи от клиента

- **WHEN** в карточке задачи, открытой из карточки клиента, пользователь редактирует задачу, убирает
  клиента и сохраняет
- **THEN** карточка задачи остаётся открытой, а задача пропадает с вкладки «Задачи» карточки клиента

#### Scenario: Раздел выключен

- **WHEN** раздел «Задачи» карточки клиента выключен, у клиента есть задачи
- **THEN** в карточке клиента нет вкладки «Задачи» и действия «Создать задачу», а в разделе «Задачи»
  приложения задачи клиента видны
