## Context

Страница — `web/src/clients/ClientsPage.tsx` (шапка через `PageHeader`, поиск, чипы-виды с
`aria-pressed`, чипы фильтров, `SelectionBar`) и `ClientListTable.tsx` (таблица `≥ md` в рамке
`rounded-md border`, список карточек `< md`). Состояние списка — search-параметры адреса
(`clientListSearch.ts`: `clientListFilters`, `searchOf`, `viewOf`). Ответ `clients/list` содержит
`groups: { id, name }[]` и `balance`, поэтому чипы-ссылки на группы и метка баланса не требуют новых
данных.

Образцы оформления: чипы видов в `tasks/TasksPage.tsx`; липкая строка на телефоне в
`groups/GroupDetailPage.tsx`; карточки `rounded-xl border bg-card shadow-xs` и рамочные чипы групп
в `clients/ClientOverviewTab.tsx` / `ClientGroupsSection.tsx`. Макет — `mockups/clients-list.html`.

## Goals / Non-Goals

**Goals:**
- Список в стиле «Обзора» карточек без изменения данных, запросов и адреса страницы.
- Правило пустого состояния — чистая функция от фильтров, тестируемая без DOM.

**Non-Goals:**
- Новые поля списка (абонемент, последний визит, неоплаченные занятия), счётчики видов,
  вид «Без абонемента» или «Заканчивается» — требуют изменений проекции `DbClientListView`.
- Смена правила «Должники» (сейчас — отрицательный баланс).
- Изменение `SelectionBar`: она общая со страницей задач и остаётся прежней.
- Оформление других списков (группы, сотрудники, задачи).

## Decisions

**Виды — чипы, не вкладки.** Вид — набор фильтров, а не панель содержимого: у него нет `tabpanel`,
и состояние «ни один вид» (`viewOf` → `null`) законно. Вкладки в проекте переключают содержимое
(карточка группы, карточка клиента), а быстрые фильтры, сохранённые виды и активные фильтры — чипы
(`web-client/filter-chips`). Виды — `button` с `aria-pressed` в `role="group"` с подписью,
оформление — как у видов задач. Подчёркнутые вкладки пробовали и отклонили: смешивали фильтр с
навигацией по содержимому и расходились с остальными списками.

**Счётчик — строка под заголовком через `PageHeader`.** `PageHeader` получает необязательный
`description?: ReactNode`; без него разметка прежняя, остальные страницы не меняются. Размер
заголовка общий для всех страниц и не меняется — иначе «Клиенты» выбивались бы среди «Групп» и
«Сотрудников».

**Чипы групп — `Link` на `/groups/$groupId` поверх растянутой ссылки строки.** Строка уже открывает
карточку растянутой ссылкой (`after:absolute after:inset-0`); чипы, как чекбокс и карандаш, получают
`relative z-10`. Показываются первые две группы в порядке ответа, остальные — `+N` с `title`, где
перечислены скрытые. Разворачивание «+N» по клику отклонено: строка таблицы меняла бы высоту.
На телефоне чипов нет — вся строка ссылка, группы идут текстом под именем, как сейчас.

**Метка баланса — общий компонент `ClientBalance`.** Одна функция оформления для таблицы и мобильной
строки (`neg | zero | pos` по `minorUnits`), чтобы правило не расходилось между раскладками.

**Пустое состояние — чистая функция `clientListEmptyState(filters)`** в `clientListSearch.ts`:
`"no-clients" | "view-empty" | "no-results"`. `view-empty` — когда `q` пуст и `viewOf(filters)` —
`debt`, `no-group` или `archived`; `no-clients` — `q` пуст и вид `all`; иначе `no-results`. Текст
вида выбирает компонент исчерпывающим `switch` по `ClientViewId`. Пример: вид «Без группы» +
фильтр «Женский» → `viewOf` = `null` → `no-results` с «Сбросить фильтры».

**Сброс фильтров** — `onSearchChange(searchOf({ ...defaults, sort, dir }))`: значения вида «Все»,
пустой поиск, текущая сортировка. Локальное поле поиска синхронизируется существующим механизмом
`syncedQ`.

**Телефон.** Порог `md` (768 px), как сейчас. Строка чипов-видов — `sticky top-14` с отрицательными
полями и горизонтальной прокруткой, как вкладки группы. «Колонки» — `hidden md:inline-flex`; у «Новый
клиент» и «Фильтры» подпись `sr-only md:not-sr-only`: на телефоне видна только иконка, доступное
название то же, и в DOM нет второй кнопки с тем же названием.

## Risks / Trade-offs

- [Чип «+N» прячет группы; подсказка `title` не видна на сенсорном экране] → на телефоне чипов нет,
  группы перечислены полностью текстом; на компьютере все группы видны в карточке клиента.
- [Убрали карандаш на телефоне] → редактирование — действие «⋯ → Редактировать анкету» в карточке,
  один лишний переход; строка на телефоне становится свободнее для имени.
- [Тесты ищут кнопки видов по роли и `aria-pressed`] → роль и атрибут сохраняются, меняются только
  классы; тесты счётчика переносятся на текст под заголовком.
