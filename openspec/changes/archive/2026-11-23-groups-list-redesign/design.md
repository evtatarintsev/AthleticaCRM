## Context

Страница — `web/src/groups/GroupsPage.tsx`: шапка через `PageHeader`, поиск с задержкой
`SEARCH_DEBOUNCE_MS`, кнопки «Дисциплины» и «Тренеры» с бейджами, открывающие `MultiSelectPicker`,
голая `Table` из `components/ui/table` и строка «Групп пока нет» / «Ничего не найдено» по признаку
«есть поиск или фильтры». Состояние — search-параметры адреса (`groupListSearch.ts`: `groupListFilters`,
`searchOf`, `groupListRequest`); `create` в адресе держит открытой панель создания.

Ответ `groups/list` (`DbGroupListView`) содержит все группы филиала под фильтр без пагинации и `total` —
число всех групп филиала **без** фильтров. Строка: `name`, `schedule` (действующие слоты с `hallName`),
`scheduleChangeAt`, `employees`. Новых данных оформлению не нужно.

Сейчас расписание собирается локальной `scheduleSummary` в одну строку без зала («Пн Ср Пт 18:00–19:30;
Сб …»), а пометка о смене расписания подставляет `scheduleChangeAt` в текст как есть — пользователь
видит `2026-12-01`.

Образцы оформления: карточка-таблица и чипы фильтров в `clients-list-redesign` (макет
`clients-list.html`), каркас карточек главной (`home/WidgetCard.tsx`). Макет —
`mockups/groups-list.html`.

## Goals / Non-Goals

**Goals:**
- Список групп в стиле списка клиентов и главной без изменения данных, запроса и адреса страницы.
- Правило пустого состояния — чистая функция, тестируемая без DOM.

**Non-Goals:**
- Новые поля списка (дисциплины, число клиентов, ближайшее занятие, требующие внимания) — отклонены
  вместе с вариантом «карточки групп», требуют изменения проекции.
- Сортировка, выбор строк, групповые действия, архив групп.
- Карточка группы и панель создания — без изменений.

## Decisions

**Строки расписания — существующая `mergedScheduleRows`.** Функция из `groupOverview.ts` уже склеивает
слоты с одинаковыми временем и залом в строку `{ days, startAt, endAt, hallName }` — так её использует
мобильная карточка «Расписание» на «Обзоре» группы. Локальная `scheduleSummary` в `GroupsPage.tsx`
удаляется. Дни — `t("day.X")` через запятую, время — `format.time`, зал — после « · ». Альтернатива —
дописать зал в `scheduleSummary` — оставила бы два правила склейки слотов.

**Таблица — `Table` в обёртке-карточке.** Берём существующую `Table` в обёртке
`rounded-2xl border bg-card shadow-sm overflow-hidden` (как `WidgetCard`), шапку — `bg-accent`. Клик по
строке — растянутая ссылка названия (`after:absolute after:inset-0` на `Link`, `relative` на строке),
как в списке клиентов: строка остаётся одним фокусируемым элементом-ссылкой, без `onClick` на `tr`.

**Мобильный список — отдельная разметка под `md:hidden`**, таблица — `hidden md:block`. Порог `md`
(768 px), как у списка клиентов и главной. Альтернатива — перестраивать ячейки таблицы CSS-ом — ломает
семантику таблицы для скринридера.

**Счётчик — `description` у `PageHeader`.** Необязательный проп `description?: ReactNode` — строка под
заголовком; без него разметка прежняя. Та же правка есть в `clients-list-redesign`: реализуемое вторым
изменение берёт готовый проп. Число — `groups.length` (ответ не постраничный), текст —
plural-ключ словаря.

**Пустое состояние — `groupListEmptyState(total, shown)`** в `groupListSearch.ts`:
`"no-groups"` при `total === 0`, `"no-results"` при `total > 0 && shown === 0`, иначе `null`.
Опора на `total` сервера, а не на «есть ли поиск»: при пустом филиале и фильтре из старой ссылки
пользователь видит «Групп пока нет», а не «Ничего не найдено». При `no-groups` поиск, фильтры и
счётчик не рисуются.

**Сброс фильтров — `onSearchChange({ ...panelOf(search) })`:** пустые `q`, `disciplineIds`,
`employeeIds`; открытая панель создания не закрывается. Локальное поле поиска синхронизируется
существующим механизмом `syncedQ`.

**Чипы — по одному на выбранное значение.** Имена берутся из уже загружаемых `useGroupDisciplines` и
`useGroupEmployees`; значение, которого нет в справочнике (удалённая дисциплина из старой ссылки),
чипа не получает, но остаётся в фильтре до «Сбросить фильтры». Крестик — `setFilters` без этого id.
Подписи «Дисциплина:» / «Тренер:» — ключи словаря; у крестика — доступное название «Убрать фильтр
«{name}»».

**Фильтры на телефоне — `DropdownMenu` из одной кнопки-иконки** с пунктами «Дисциплины» и «Тренеры»
(у пункта — число выбранных), каждый открывает существующий `MultiSelectPicker`. Бейдж кнопки —
`disciplineIds.length + employeeIds.length`, как сумма бейджей двух кнопок на компьютере. Альтернатива —
две кнопки-иконки с одинаковым значком — неразличимы.

**Пометка о смене расписания** — «Новое расписание с {date}», дата `дд.мм.гггг` («01.12.2026»), цвет
`text-amber-700 dark:text-amber-300`; ключ `groups.scheduleChangeNote` меняет текст в `ru.ts` и `en.ts`.
Для даты в `format.ts` добавляется `format.numericDate`: `Intl.DateTimeFormat` с
`{ day: "2-digit", month: "2-digit", year: "numeric", timeZone: "UTC" }`, как `format.date` — без сдвига
по часовому поясу; для `ru` это `01.12.2026`. Существующий `format.date` («1 дек. 2026 г.») используется
по всему приложению и не меняется. Альтернатива — собирать строку из частей `LocalDate` вручную — дала бы
`дд.мм.гггг` и в английском интерфейсе, где привычен другой порядок.

## Risks / Trade-offs

- [Правка `PageHeader` пересекается с `clients-list-redesign`] → проп необязательный и одинаковый в обоих
  изменениях; при слиянии второго — разрешить конфликт в пользу уже влитой версии.
- [Значение фильтра без справочника не видно чипом] → бейдж его считает, «Сбросить фильтры» снимает;
  случай возможен только со старой ссылкой на удалённую дисциплину или уволенного тренера.
- [Длинный список тренеров в узкой колонке] → имена переносятся внутри ячейки, строка растёт по высоте;
  обрезка с «+N» отклонена вместе с аватарами.
