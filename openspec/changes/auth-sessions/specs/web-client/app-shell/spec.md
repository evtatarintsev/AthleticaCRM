# Spec Delta

## MODIFIED Requirements

### Requirement: Выход

Выход SHALL завершать сессию на сервере, очищать все загруженные данные в памяти клиента и открывать страницу входа. После выхода прежние токены этой сессии SHALL NOT приниматься сервером.

#### Scenario: Выход и кнопка «Назад»

- **WHEN** пользователь вышел и нажал в браузере «Назад»
- **THEN** данные прежней сессии не показываются, открывается страница входа

#### Scenario: Сеанс завершён с другого устройства

- **WHEN** текущий сеанс завершили с другого устройства, а пользователь открывает список клиентов
- **THEN** обновление сессии не удаётся, открывается страница входа с возвратом на список клиентов
