## 4. Клиенты (п. 5)

- [x] 4.1 Переходы архивации и восстановления перенести из `ClientsRoutes` в домен (`CLIENT_ALREADY_ARCHIVED`, `CLIENT_NOT_ARCHIVED`) условной записью по существующему полю `state` (`UPDATE clients SET state = 'ARCHIVED' ... WHERE state = 'ACTIVE'` и обратно), ноль обновлённых строк — доменная ошибка. Тест: повторный переход отклоняется, два параллельных архивирования дают одну запись аудита
- [x] 4.2 Редактирование профиля, замену контактов, корректировку баланса и документы выполнять только через `ActiveClient` в домене, а не через `requireActive` в маршруте. Загруженный `ActiveClient` не защищает от параллельной архивации, поэтому каждая такая запись в своей транзакции либо обновляет клиента условно (`WHERE state = 'ACTIVE'`), либо сначала блокирует его строку (`SELECT ... FOR UPDATE`) и перепроверяет `state`. Тест: прямой доменный вызов для архивного клиента отклоняется; две транзакции — архивация и корректировка баланса (и изменение профиля) одного клиента — не дают изменения, записанного после архивации
