## ADDED Requirements

### Requirement: Фильтр расписания по группе

Расписание SHALL поддерживать фильтр по группам: при заданном фильтре показываются только занятия выбранных групп. Фильтр по группам SHALL объединяться с остальными фильтрами по «и» и SHALL сохраняться в адресе страницы, чтобы на расписание с фильтром можно было перейти по ссылке. Активный фильтр по группе SHALL быть виден на странице с названием группы и SHALL сниматься пользователем. Фильтр SHALL сохраняться при переключении недели.

#### Scenario: Переход по ссылке с фильтром группы

- **WHEN** пользователь открывает расписание по адресу с фильтром по группе
- **THEN** показаны только занятия этой группы, а на странице виден активный фильтр с её названием

#### Scenario: Фильтр по группе вместе с другими

- **WHEN** выбраны фильтр по группе и фильтр по залу
- **THEN** показаны только занятия этой группы, проходящие в выбранном зале

#### Scenario: Снятие фильтра по группе

- **WHEN** пользователь снимает фильтр по группе
- **THEN** расписание показывает занятия всех групп с учётом остальных фильтров, и фильтр по группе исчезает из адреса

#### Scenario: Группа другого филиала

- **WHEN** в адресе указан фильтр по группе, не принадлежащей текущему филиалу
- **THEN** занятия не показываются и показано сообщение об отсутствии занятий с активным фильтром, доступным для снятия
