# Макеты клиентского приложения

Согласованные макеты из артефакта https://claude.ai/artifact/USGK1UdgF7BxB3kEoDS8ox
(строки «Подключение и вход», «Приложение клиента», «CRM: что видит администратор»).
Сохранены как статичный HTML (390×844 для телефона, 1040×780 для CRM): открываются в браузере,
ссылки между экранами работают. Это отправная точка для дизайна кабинета, а не пиксельный эталон;
варианты стиля и экраны по видам спорта в изменение не входят.

## Подключение и вход

| Экран | Файл |
|---|---|
| 1. Вход по номеру | [Main.html](Main.html) |
| 2. Код подтверждения | [Code.html](Code.html) |
| 3. Приглашения организаций | [Invites.html](Invites.html) |
| 4. Проверка даты рождения | [Verify.html](Verify.html) |
| 5. Проверка не пройдена | [Blocked.html](Blocked.html) |

Защита от ошибки в номере (заметка с макета):

1. Войти можно только по приглашению организации.
2. До проверки человек видит только название организации, никаких имён и данных.
3. Дату рождения спрашиваем по каждому клиенту отдельно: открываем только тех, чья дата совпала.
4. Три ошибки — подключение приостановлено, администратор получает задачу «Проверьте номер».
5. Кнопка «Это не я» — честный посторонний сам сообщает об ошибке.
6. Тот же вопрос при входе с нового телефона (защита от номеров, которые оператор отдал другому).
