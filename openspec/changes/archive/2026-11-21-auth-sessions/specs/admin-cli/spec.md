# Spec Delta

## MODIFIED Requirements

### Requirement: Сброс пароля пользователя

Команда `admin user reset-password` SHALL принимать логин пользователя и заменять его пароль новым, не требуя старого пароля. Пользователь SHALL определяться по точному совпадению логина, без указания организации. После сброса пользователь SHALL входить с новым паролем, а старый пароль SHALL перестать подходить для входа.

#### Scenario: Пароль сброшен

- **WHEN** выполняется `admin user reset-password` с логином существующего пользователя и вводится новый пароль
- **THEN** пароль пользователя заменяется новым, вход с новым паролем проходит, вход со старым паролем отклоняется, и выводится сообщение об успешной смене пароля с логином пользователя

#### Scenario: Пользователь не найден

- **WHEN** логин не соответствует ни одному пользователю
- **THEN** выводится сообщение об ошибке в поток ошибок, приложение завершается с ненулевым кодом возврата, пароли пользователей не изменяются

#### Scenario: Пользователь — сотрудник нескольких организаций

- **WHEN** логин уже принадлежит сотруднику одной организации и его пытаются привязать к сотруднику другой
- **THEN** привязка отклоняется, поэтому сброс пароля всегда относится ко входу в одну организацию
