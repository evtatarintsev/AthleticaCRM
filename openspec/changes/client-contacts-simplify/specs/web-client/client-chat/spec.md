# Spec Delta

## ADDED Requirements

### Requirement: Адрес получателя по умолчанию

При выборе канала, который адресует клиента по контакту (например, SMS — по телефону), адресом
получателя по умолчанию SHALL быть основной контакт клиента нужного каналу типа
(см. `client-contacts`). Сотрудник SHALL иметь возможность выбрать другой контакт этого типа.

#### Scenario: SMS на основной телефон

- **WHEN** у клиента телефоны «мама» (добавлен первым) и «папа» (основной), и сотрудник выбирает
  SMS-канал
- **THEN** получателем выбран номер «папа», номер «мама» доступен в выборе адреса
