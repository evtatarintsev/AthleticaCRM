## ADDED Requirements

### Requirement: Погашение отклоняется целиком при недопустимом занятии

Набор для погашения SHALL содержать хотя бы одно занятие, пустой набор SHALL отклоняться с ошибкой `DEBT_SESSIONS_REQUIRED`. Каждое выбранное для погашения занятие SHALL быть неоплаченным занятием этого клиента в одной из групп абонемента. Если хотя бы одно выбранное занятие этому не соответствует, погашение SHALL отклоняться целиком, ни одно занятие SHALL NOT списываться. Повторно указанное занятие SHALL учитываться один раз, в том числе при сравнении с остатком.

#### Scenario: Занятие другой группы

- **WHEN** сотрудник выбирает для погашения два занятия, одно из которых в группе, не входящей в абонемент
- **THEN** погашение отклоняется, ни одно занятие не списано

#### Scenario: Занятие другого клиента

- **WHEN** среди выбранных занятий есть участие другого клиента
- **THEN** погашение отклоняется, ни одно занятие не списано

#### Scenario: Занятие уже оплачено

- **WHEN** среди выбранных есть занятие, за которое уже есть действующее списание
- **THEN** погашение отклоняется с ошибкой «занятие уже списано», ни одно занятие не списано

#### Scenario: Повтор в выборе

- **WHEN** у абонемента остаток 1, и сотрудник дважды указал одно и то же неоплаченное занятие
- **THEN** занятие списано один раз, остаток 0

#### Scenario: Пустой набор

- **WHEN** сотрудник отправляет погашение без выбранных занятий
- **THEN** погашение отклоняется с `DEBT_SESSIONS_REQUIRED`, абонемент и история не изменяются

#### Scenario: Погашение одновременно с автоматическим списанием

- **WHEN** сотрудник погашает неоплаченное занятие с абонемента, а одновременно правка отметки запускает автоматическое списание того же занятия с того же абонемента
- **THEN** обе операции завершаются без ошибки сервера, занятие списано один раз; погашение, оказавшееся вторым, отклоняется с ошибкой «занятие уже списано»
