## ADDED Requirements

### Requirement: Погашение отклоняется целиком при недопустимом занятии

Каждое выбранное для погашения занятие SHALL быть неоплаченным занятием этого клиента в одной из групп абонемента. Если хотя бы одно выбранное занятие этому не соответствует, погашение SHALL отклоняться целиком, ни одно занятие SHALL NOT списываться. Повторно указанное занятие SHALL учитываться один раз, в том числе при сравнении с остатком.

#### Scenario: Занятие другой группы

- **WHEN** сотрудник выбирает для погашения два занятия, одно из которых в группе, не входящей в абонемент
- **THEN** погашение отклоняется, ни одно занятие не списано

#### Scenario: Занятие другого клиента

- **WHEN** среди выбранных занятий есть участие другого клиента
- **THEN** погашение отклоняется, ни одно занятие не списано

#### Scenario: Занятие уже оплачено

- **WHEN** среди выбранных есть занятие, за которое уже есть действующее списание
- **THEN** погашение отклоняется с ошибкой «занятие уже списано», ни одно занятие не списано

#### Scenario: Повтор в выборе

- **WHEN** у абонемента остаток 1, и сотрудник дважды указал одно и то же неоплаченное занятие
- **THEN** занятие списано один раз, остаток 0
