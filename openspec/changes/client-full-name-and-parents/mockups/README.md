# Макет формы клиента

`client-form.html` — кликабельный прототип формы «Новый клиент», согласованный владельцем.
Опубликован как артефакт https://claude.ai/artifact/4aVwYw1JNxijDNViDcD2to.

Открыть локально — просто в браузере. Панель «Прототип» сверху заполняет форму примерами
(ребёнок, подросток, взрослый, без даты рождения).

Расхождение со спецификацией: строка контакта в прототипе позволяет менять тип; верна
спецификация `web-client/client-contacts` — тип задаётся при добавлении.
