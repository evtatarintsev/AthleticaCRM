# Proposal

## Why

Клубы переносят клиентскую базу из таблиц (csv, xlsx) и бумажных журналов. Импорт в настройках принимает только CSV, требует вручную сопоставить колонки и не переносит контакты, а фото журнала не принимает вовсе. AI-помощник уже умеет создавать клиента с подтверждением. Если отдать ему файл, перенос базы сведётся к короткому диалогу: пользователь бросает файл, отвечает на пару вопросов и нажимает «Создать».

## What Changes

- В чат помощника можно приложить файл: одну таблицу csv/xlsx или до 10 фото журнала в одном сообщении.
- Сервер сам превращает файл в таблицу строк: таблицы читает детерминированно, фото распознаёт через отдельно подключаемый сервис распознавания с пометкой неуверенных ячеек.
- Модель помощника получает только структуру таблицы: заголовки, первые строки и набор различающихся значений коротких колонок. По ним она строит сопоставление колонок с полями клиента и задаёт уточняющие вопросы, только если однозначного ответа нет: формат даты, значения пола, лишние колонки, неразборчивые ячейки.
- Сервер применяет сопоставление ко всем строкам и показывает пакетную карточку: сколько клиентов будет создано, строки с ошибками, найденные и возможные дубли, превью.
- Переносятся только карточка клиента (ФИО, пол, дата рождения, дополнительные поля) и контакты. Баланс, источник клиента, группы и абонементы не переносятся.
- Дубли проверяются по телефону среди клиентов организации и внутри файла. Совпадения только по ФИО обсуждаются одним групповым вопросом, а не по одному человеку.
- Исправления пользователь пишет сообщением, и каждое заменяет карточку новой. Подтверждение кнопкой или ответом создаёт все готовые строки в одной транзакции, повтор подтверждения идемпотентен.
- Импорт в настройках не меняется.

## Capabilities

### New Capabilities
- `ai-assistent-client-import`: перенос клиентов из файлов через диалог с помощником — приём файлов, получение строк, сопоставление полей, дубли, пакетная карточка, подтверждение и сохранение, ограничение данных для провайдеров.
- `web-client/ai-assistent-client-import`: прикрепление файлов в чате помощника, пакетная карточка импорта, её состояния и результат.

### Modified Capabilities
- `ai-assistent`: помощник исполняет не только создание одного клиента, но и операции импорта; сообщение может содержать вложения; ход с вложениями имеет собственный предел времени.

## Impact

- **БД**: таблицы источников импорта (полученные строки) и пакетных черновиков помощника (миграция Liquibase).
- **server**: `assistant/` — tools импорта, расширение `AssistantService.send`, `AssistantRunner` (промпт, пределы хода), `AssistantStorage` (вложения сообщения, срок хода); новый компонент распознавания фото с отдельным подключением; чтение xlsx; повторное использование `CsvReader`, `ValueParsers`, `PhoneDigits`; `Di.kt`.
- **Зависимость**: библиотека чтения xlsx (новая).
- **Конфигурация**: необязательные `assistant.recognition.*` (провайдер, модель, ключ) в `application.conf`, `docker-compose.prod.yaml`, `.env.prod.example`. Без них импорт фото недоступен, таблицы работают.
- **shared**: `AssistantSendRequest` получает вложения; новые блоки `AssistantBlock` для пакетной карточки и результата; запрос подтверждения пакета.
- **web**: прикрепление файлов в `AssistantHost`, пакетная карточка, строки RU/EN, перегенерация `web/src/api/generated/`.
- **152-ФЗ**: для таблиц модели передаётся только образец, фото целиком уходят только в сервис распознавания. Провайдер выбирается при установке, например Яндекс для РФ.
