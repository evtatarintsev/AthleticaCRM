## ADDED Requirements

### Requirement: Автор «Система» у системных задач

Для задачи, созданной системой, карточка и список задач SHALL показывать автора «Система» вместо имени сотрудника. Остальное поведение карточки (смена статуса, исполнителя, вложений, редактирование) SHALL совпадать с обычной задачей.

#### Scenario: Системная задача в карточке

- **WHEN** пользователь открывает задачу «Проверить клиента», созданную системой
- **THEN** автор показан как «Система», клиент — ссылкой, исполнитель — «Не назначен»

#### Scenario: Назначение системной задачи

- **WHEN** пользователь назначает себя исполнителем системной задачи
- **THEN** исполнитель сохраняется, автор остаётся «Система»
