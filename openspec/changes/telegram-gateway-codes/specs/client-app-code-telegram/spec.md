## Purpose

Доставка одноразового кода входа в клиентское приложение через Telegram по номеру телефона, без бота организации и без предварительного контакта с человеком.

## ADDED Requirements

### Requirement: Код приходит в Telegram по номеру

Код входа по каналу Telegram SHALL доставляться сообщением от официального отправителя кодов Telegram на аккаунт, привязанный к номеру телефона. Человеку SHALL NOT требоваться заранее писать боту или подписываться на что-либо.

#### Scenario: Первый вход

- **WHEN** мама впервые запрашивает код, и к её номеру привязан аккаунт Telegram
- **THEN** код приходит ей в Telegram

### Requirement: Недоставляемый номер

Если Telegram не может доставить сообщение на номер (к номеру не привязан аккаунт или отправка на него недоступна), отправитель SHALL сообщать об этом до отправки, не тратя попытку доставки, чтобы код ушёл по SMS в том же запросе.

#### Scenario: Нет аккаунта Telegram

- **WHEN** к номеру папы не привязан аккаунт Telegram, и он запрашивает код
- **THEN** код приходит ему по SMS, приложение показывает «Код отправлен по SMS»

### Requirement: Сообщение живёт столько же, сколько код

Сообщение с кодом в Telegram SHALL истекать не позже, чем истекает сам код (5 минут).

#### Scenario: Код истёк

- **WHEN** прошло 5 минут после отправки
- **THEN** сообщение с кодом в Telegram помечено истёкшим

### Requirement: Код и ключ не попадают в журналы

Ни код, ни ключ Gateway API SHALL NOT записываться в журналы приложения. Ошибки отправки SHALL записываться в журнал с номером в обезличенном виде.

#### Scenario: Ошибка отправки

- **WHEN** Gateway API ответил ошибкой
- **THEN** в журнале есть причина и последние 4 цифры номера, кода и ключа нет
