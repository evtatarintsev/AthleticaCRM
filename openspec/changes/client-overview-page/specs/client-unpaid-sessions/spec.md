## Purpose

Неоплаченные занятия клиента во всех группах организации позволяют увидеть весь долг по занятиям,
включая разовые посещения и посещения без ранее выданного абонемента.

## ADDED Requirements

### Requirement: Неоплаченные занятия клиента во всех группах

Система SHALL предоставлять список неоплаченных занятий клиента (`membership-debits`: проведённое
занятие с отметкой «пришёл» без действующего списания) во всех группах организации, от старых к
новым. Для каждого занятия SHALL возвращаться занятие, дата, время начала и группа. Список SHALL
собираться одним запросом в пределах организации текущего сотрудника.

#### Scenario: Занятия в разных группах

- **WHEN** у клиента неоплаченное занятие в группе «Младшие» от 13.10 и в группе «ОФП» от 15.10
- **THEN** список содержит оба занятия: сначала 13.10 «Младшие», затем 15.10 «ОФП»

#### Scenario: Клиент без абонементов

- **WHEN** у клиента никогда не было абонемента, но есть проведённое занятие с отметкой «пришёл»
  без действующего списания
- **THEN** это занятие есть в списке неоплаченных

#### Scenario: Разовое посещение вне текущих групп

- **WHEN** клиент разово посетил проведённое занятие группы, в которой сейчас не состоит,
  и действующего списания нет
- **THEN** занятие есть в списке независимо от текущего состава групп и групп абонементов

#### Scenario: Списанное занятие со сторнированием

- **WHEN** единственное списание за проведённое занятие с отметкой «пришёл» сторнировано
- **THEN** занятие снова есть в списке неоплаченных

#### Scenario: Отсутствие и непроведённые занятия

- **WHEN** у клиента есть отметка «не пришёл», запланированное и отменённое занятия
- **THEN** эти занятия не попадают в список неоплаченных

#### Scenario: Оплаченное не попадает

- **WHEN** занятие клиента списано с абонемента
- **THEN** его нет в списке неоплаченных

#### Scenario: Погашенный долг

- **WHEN** неоплаченное занятие погашено с абонемента
- **THEN** его больше нет в списке

#### Scenario: Клиент другой организации

- **WHEN** запрошены неоплаченные занятия клиента, которого нет в организации
- **THEN** возвращается ошибка `CLIENT_NOT_FOUND`

#### Scenario: Неизвестный клиент

- **WHEN** запрошены неоплаченные занятия несуществующего клиента
- **THEN** возвращается ошибка `CLIENT_NOT_FOUND`, а не пустой список

#### Scenario: Изоляция занятий

- **WHEN** клиент есть в текущей организации, но связанное с ним занятие относится к другой
- **THEN** занятие другой организации не возвращается
