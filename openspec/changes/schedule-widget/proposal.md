# Proposal

## Why

Клубы публикуют расписание на своём сайте и в сообществе ВКонтакте. Сейчас его приходится
переписывать вручную, и оно расходится с CRM при каждом переносе или отмене занятия.
У конкурентов есть встраиваемый виджет расписания, у нас нет.

## What Changes

- Новый раздел настроек «Виджеты расписания»: виджеты создаются, редактируются, выключаются
  и удаляются. У каждого виджета есть название, филиал, горизонт показа (по умолчанию месяц),
  переключатели полей (тренеры выключены по умолчанию, зал и дисциплины включены) и список
  исключённых групп.
- У виджета есть публичный ключ. Ключ можно перевыпустить, после этого старая ссылка
  перестаёт работать.
- У группы появляется признак «показывать в виджетах» (по умолчанию включён). Его задают
  при создании и редактировании группы. Группа с выключенным признаком не попадает ни в один
  виджет.
- Публичная страница виджета `https://app.<домен>/widget/<ключ>` работает без входа и
  предназначена для iframe. На широком экране она показывает неделю, на узком — день.
  Отменённые занятия показываются с пометкой. Неверный ключ и выключенный виджет дают
  одинаковую страницу «расписание недоступно».
- Публичный API расписания виджета без авторизации. В ответе нет внутренних идентификаторов
  и служебных признаков.
- В настройках виджета есть предпросмотр, код iframe для сайта и инструкция для ВКонтакте
  (приложение сообщества или кнопка со ссылкой). Интеграции с API ВКонтакте нет.
- Новое право `CAN_MANAGE_WIDGETS` на управление виджетами.
- Страницы CRM на `app.<домен>` запрещено встраивать в чужие страницы, кроме страницы виджета.

## Capabilities

### New Capabilities

- `schedule-widgets`: управление виджетами расписания: состав настроек, публичный ключ,
  право на управление, признак группы «показывать в виджетах» и правила отбора занятий.
- `public-schedule-widget`: публичная страница виджета и её API: что видит посетитель сайта
  или ВКонтакте, ответ на неверный или выключенный ключ, встраивание в iframe.

### Modified Capabilities

- `public-site`: на хосте CRM добавляется запрет на встраивание страниц в iframe, кроме
  страницы виджета.

## Impact

- **БД**: новые таблицы виджетов и исключённых групп, колонка признака у `groups`.
- **server**: новый домен `domain/widgets`, проекция `read/widgets`, маршруты управления
  виджетами (с входом) и публичный маршрут (без входа, вне `authenticate`), новое право
  в `Permission`, изменения создания и редактирования группы.
- **shared**: схемы запросов и ответов виджетов и публичного расписания, признак в схемах
  группы.
- **web**: публичный маршрут `/widget/$key` вне `AppLayout`, раздел настроек виджетов,
  переключатель в формах группы, подпись права в словарях; перегенерация контрактов.
- **nginx**: `frame-ancestors` для хоста `app.` в `prod.conf.template` и `dev.conf`.
