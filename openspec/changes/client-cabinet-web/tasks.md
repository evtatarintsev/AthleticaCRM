- [ ] 3.2 Usecase запроса кода: 6 цифр, хэш SHA-256 от `id` и кода (design §5), TTL 5 мин, строка кода на каждый запрос, лимиты 60 с, 5/час и 10/сутки одинаково для любого номера; ответ без канала, доставка после ответа в фоне, выбор канала и переход на SMS при `Undeliverable` (design §8); плательщик — только организация с включённым кабинетом; тесты на лимиты (в том числе для постороннего номера), истечение, 5 неверных попыток, переход на SMS, «ответ для постороннего и приглашённого номера одинаков», «посторонний номер — доставка не запускается», «кабинет выключен — организация не платит» на заглушках
- [ ] 3.3 Отправитель `TELEGRAM` над `TelegramGateway` (design §8): выбор организации с включённым кабинетом, самым свежим приглашением и включённым Gateway, отправка в её `SystemRequestContext` вне транзакции, `NotConfigured`/`Undeliverable` → `Undeliverable`; тесты на выбор организации и на переход в SMS на фейковом `TelegramGateway`; отправитель `SMS` через `ChannelTransports` SMS-канала организации (design §8), окончательный отказ → `Failed`; тесты на выбор организации и «у пригласившей организации нет SMS-канала» на фейковом транспорте
