## Why

Какие группы растут, а какие теряют клиентов, не видно: состав группы показывается только на
сегодня, без сравнения с прошлым и без списка ушедших.

Зависит от `reports-page`: страница раздела, заглушка виджета, фильтры периода и филиала,
шаблоны виджета и экрана отчёта, библиотека графиков.

Макет: `reports-page/mockups/reports.html#groups`.

## What Changes

- Заглушка виджета «Группы» заменяется настоящим: быстрее всех растущая группа, прирост
  клиентов, предупреждение о группе, которая больше всех теряет.
- Страница «Группы»: главная цифра с графиком клиентов во всех группах по неделям; плитки
  «Групп», «Растут», «Теряют клиентов»; клиентов в группах сейчас и месяц назад; подробная таблица
  по группам (клиенты, посещаемость, человек на занятии, выручка); список ушедших из групп.
- Правило подсчёта: рост группы — сколько в ней клиентов сейчас и сколько было месяц назад.
  Отчёт есть у всех клубов, даже с одним видом спорта.
- Колонка выручки — только с правом просмотра финансов.
- **BREAKING**: нет.

## Capabilities

### New Capabilities
- `reports-groups`: рост и потеря клиентов по группам за период, список ушедших.
- `web-client/reports-groups`: виджет и страница «Группы».

### Modified Capabilities
- нет.

## Impact

- `server/.../read/reports/`: проекция групп; маршрут `reports/groups`; DB-тест.
- `shared/.../api/schemas/reports/`; перегенерация `web/src/api/generated/`.
- `web/src/reports/groups/`; словари.
- Пересекается с `group-roster` (история состава), `attendance-journal`.
- Открытый вопрос (`design.md`): как делить выручку абонемента на несколько групп.
