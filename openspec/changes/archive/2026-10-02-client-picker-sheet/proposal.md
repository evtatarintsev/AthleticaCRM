## Why

В карточке группы нельзя изменить её состав: секция «Клиенты» — только список ссылок, без добавления и удаления (#108). Клиента можно записать в группу лишь из его собственной карточки, по одному, а массовое добавление (UC-1.4.4) со стороны группы недоступно вовсе.

Выбор клиента нужен не только группе: он уже есть на карточке занятия (добавление разового участника) и понадобится при выдаче абонементов. Сейчас каждый экран делает свою шторку снизу со своим поиском — с появлением панели справа (`EditSheet`) пора сделать один переиспользуемый выбор клиента.

## What Changes

- Появляется **панель выбора клиента** справа на базе `EditSheet`: поиск по имени, список клиентов организации с догрузкой порциями, режимы «один клиент» и «несколько клиентов». Вызывающий экран передаёт недоступных клиентов с причиной (например, «уже в группе») — они видны в списке, но выбрать их нельзя. Отмеченные, но не подтверждённые клиенты считаются несохранёнными изменениями.
- В карточке группы в секции «Клиенты» появляется **добавление клиентов**: панель выбора в режиме «несколько», подтверждение кнопкой «Добавить» записывает всех отмеченных в группу одним запросом.
- В карточке группы у каждого клиента появляется **удаление из состава** крестиком, без подтверждения — как у дисциплин и тренеров.
- **Добавление разового участника занятия** переводится на ту же панель в режиме «один клиент»; прежняя шторка `AddParticipantSheet` удаляется.

### Non-goals

Фильтры в панели выбора (группа, долг, абонемент); отдельная серверная проекция для выбора клиента — пока используется `clients/list`; выдача абонемента с выбором клиента; добавление нескольких разовых участников занятия за раз (требует изменения API `sessions/journal/add-participant`); перевод шторки «Добавить в группу» в карточке клиента — там выбирается группа, а не клиент.

## Capabilities

### New Capabilities
- `web-client/client-picker`: переиспользуемая панель выбора клиента — поиск, список, режимы одиночного и множественного выбора, недоступные клиенты, подтверждение и защита несохранённого выбора.
- `web-client/group-clients`: состав группы в карточке группы — просмотр, добавление клиентов через панель выбора, удаление из состава.

### Modified Capabilities
- `web-client/session-detail`: добавление разового участника занятия выполняется через панель выбора клиента.

## Impact

- **Веб-клиент**: новый компонент `web/src/clients/ClientPickerSheet.tsx`; правки `web/src/groups/GroupDetailPage.tsx` и `web/src/sessions/SessionDetailPage.tsx` (удаление `AddParticipantSheet`); строки в `i18n/ru.ts` и `en.ts`; тесты панели, карточки группы и карточки занятия.
- **Сервер и контракты**: без изменений — используются существующие `clients/list`, `clients/add-to-group`, `clients/remove-from-group`, `sessions/journal/add-participant`.
- **Смежное**: панель станет точкой входа для будущей выдачи абонемента с выбором клиента.
