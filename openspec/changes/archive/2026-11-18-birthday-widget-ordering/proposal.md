# Proposal

## Why

Виджет «Дни рождения» исключает сегодняшних именинников при выборе «Завтра», а серверная сортировка по имени может вытеснить их за лимит карточки. Нужны накопительные периоды и сортировка по близости дня рождения, затем по имени; упорядоченный список критериев API позволит выразить этот порядок без отдельного жёстко заданного режима сортировки виджета на сервере.

## What Changes

- Периоды виджета: «Сегодня» = сегодня; «Сегодня и завтра» = сегодня…завтра; «На неделю вперёд» = сегодня…сегодня + 7 дней, обе границы включены. Селект остаётся, произвольного ввода дней нет.
- `clients/list` получает необязательный упорядоченный массив критериев `sort`, каждый со своим направлением. Старые `sortField`/`sortDirection` продолжают работать, если массив отсутствует, равен null или пуст.
- Новый критерий `NEXT_BIRTHDAY` упорядочивает месяц и день относительно начала переданного диапазона дней рождения, без учёта года рождения и с корректным переходом через декабрь. Существующий `BIRTHDAY` сохраняет сортировку по полной дате рождения.
- Виджет запрашивает `NEXT_BIRTHDAY Asc`, затем `NAME Asc`; сервер применяет все критерии до пагинации и завершает порядок идентификатором клиента.
- «Показать всех» открывает список с тем же периодом и порядком, в том числе после перезагрузки. Управление сортировкой в таблице остаётся по одной колонке.
- Сохранённые значения `TODAY`/`TOMORROW`/`WEEK`, название, лимит и положение виджета сохраняются; `TOMORROW` получает накопительную семантику. Старые самостоятельные фильтры списка клиентов «Завтра» и «На этой неделе» сохраняют прежние границы.
- Новые подписи локализуются на русском и английском.

## Capabilities

### New Capabilities

- `client-list-sorting`: составная серверная сортировка списка клиентов, совместимость старых запросов и порядок по ближайшему дню рождения.

### Modified Capabilities

- `web-client/home-dashboard`: накопительные периоды дней рождения, приоритет ближайших именинников и согласованный переход на полный список.

## Impact

- `shared/.../api/schemas/clients/ClientListRequest.kt`, `ClientSortField.kt`: массив типизированных критериев и `NEXT_BIRTHDAY`; `settings/DashboardSettings.kt`: описание нового смысла сохранённого `TOMORROW`.
- `server/.../routes/ClientsRoutes.kt`, `read/clients/ClientListView.kt`, `DbClientListView.kt`: нормализация, проверка и безопасное построение составного `ORDER BY`; тесты границы API и PostgreSQL-проекции.
- `web/src/api/generated/contracts.ts`: перегенерация из Kotlin через `npm run contracts`.
- `web/src/home/`, `web/src/clients/clientListSearch.ts`, `ClientsPage.tsx`, `ClientsFiltersSheet.tsx`, `web/src/i18n/{ru,en}.ts` и связанные тесты: запросы, подписи, адрес и отображение фильтра полного списка.
- Без новых зависимостей, миграций БД, конструктора сортировки, изменений общей схемы сохранённых сортировок и сортировки других разделов.
