## Why

Занятия вне расписания (замена, доп. тренировка, сборы) сейчас можно создать только запросом к API: в веб-клиенте для этого нет интерфейса. Создание уже поддержано на сервере (`POST /sessions/create`), но не позволяет выбрать тренеров и не проверяет, что зал принадлежит филиалу группы; та же дыра с залом есть у переноса занятия.

## What Changes

- В шапке недельной сетки расписания у каждого дня появляется действие «[+]», открывающее панель создания занятия с предзаполненной датой этого дня.
- Панель создания: дата (редактируемая), группа текущего филиала, тренеры (при выборе группы отмечаются её тренеры, состав можно изменить), зал, время начала и окончания, заметка (необязательно).
- Неделя без занятий (в том числе когда фильтрам ничего не соответствует) показывается сеткой с шапкой дней и строкой «Занятий нет» вместо отдельного сообщения — чтобы действие добавления было доступно всегда.
- **BREAKING** (API): `CreateSessionRequest` получает обязательное поле `employeeIds` (может быть пустым); сервер больше не подставляет тренеров группы сам.
- Состав тренеров, заданный при создании занятия вне расписания, не считается ручной заменой состава.
- Создание и перенос занятия отклоняются ошибкой, если зал не принадлежит организации и филиалу группы занятия.

## Capabilities

### New Capabilities

_нет_

### Modified Capabilities

- `schedule`: неделя без занятий показывается сеткой; в шапке дня — действие добавления занятия; панель создания занятия вне расписания.
- `session-generation`: явный состав тренеров ручного занятия без признака замены; проверка зала при создании и переносе занятия.

## Impact

- `shared`: `CreateSessionRequest` (+ `employeeIds`); перегенерация `web/src/api/generated/contracts.ts`.
- `server`: `usecases/sessions/CreateSession.kt`, `domain/sessions/DbSessions.kt` (`new`), `domain/sessions/DbSession.kt` (`reschedule`), тесты сессий.
- `web`: `schedule/ScheduleWeekGrid.tsx`, `schedule/SchedulePage.tsx`, новая панель создания на `EditSheet`, словари `i18n/ru.ts` / `en.ts`.
- Внешних потребителей `/sessions/create` нет: веб-клиент его пока не вызывает.
